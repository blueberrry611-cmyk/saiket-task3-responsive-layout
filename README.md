## Task

Design a webpage with four sections: a header, a sidebar, a main content area and a footer. Make it responsive with CSS, using media queries to switch between a grid layout on desktop and a stacked layout on mobile.

## Features

- Four sections: header, sidebar, main content and footer
- CSS Grid layout with named grid areas on desktop
- Media query at 700px that stacks all sections on mobile
- Semantic HTML tags (`header`, `aside`, `main`, `footer`)
- Viewport meta tag for correct scaling on phones

## How the Layout Works

| Screen width | Layout |
|---|---|
| Above 700px | Header on top, sidebar beside main content, footer at the bottom |
| 700px and below | Header, sidebar, main content, footer stacked in one column |
